## 1. 我们理解的公司运转方式

- 同时在手 3–5 套房，业务横跨 KC 和 LA ⚠。
- 定价在董事会（D、L 参与）。**每个大节点由 D 和 J 一起确认**才往下走。
- J（Jessie）身兼三职：找房 agent、采购、卖房 agent。
- 负责人（我们的对接人）是**统筹**：不亲自做事，看全局、盯进度、代人打勾、补风险备注。
- 施工现场由 PM 盯，临时安排 L+D 定；承包商不进系统，照片由 PM 传 ⚠。
- 每套房五段：买 → 贷 → 设计定稿+permit → 施工+采购 → 卖。**阶段只靠大节点推进**，后面一段零星有动作（比如先付了清理费）不算进入下一段。
- 现在的汇报是微信、电话、去现场；目标是所有人统一在系统里填，负责人打开就看到。

## 2. 五段、每件事、谁做、交什么

交付物分五种：**文件**（PDF / 合同）、**照片**（现场 / 看房 / staging）、**数据**（填一个日期或价格）、**记录**（水电瓦斯 / 检查 / 支出）、**确认**（大节点 D、J 各勾一次）。交了就自动打勾；没有交付物的只有"agent 介入"，手动勾。

| 段 | 事 | 谁 | 交付物 |
|---|---|---|---|
| ① 买 | 筛选房源 | J | 建项目、写风险（死亡记录 / 无证面积） |
| | 看房 | L | 看房照片 |
| | 董事会定价、谈价 | D、L | 买入价 |
| | ◆ Open escrow | D、J 确认 | 购房合同（可选） |
| ② 贷 | 开始贷款、买保险 | J、K | 保险单（填到期日） |
| | 签 loan doc | D、L | 签署的贷款文件 |
| | 量尺、估价 | L | 量尺记录 |
| | 设计方案 | 设计师 | 方案图纸 |
| | ◆ Close escrow | D、J 确认 | 买入日期、结算单 |
| | 开水电瓦斯 | K | 三家账户都"已开通" |
| ③ 设计定稿+permit | 设计定稿 | 设计师 | 定稿图纸 |
| | 申请 permit | Z | 申请回执 |
| | 先干不用 permit 的活 | PM | 现场照片 |
| | 拿到 permit 文件 | Z | 政府核发的 permit |
| | ◆ 可以开工 | D、J 确认 | 开工日期 |
| ④ 施工+采购 | 分阶段采购 | J | 支出记录（以后是采购清单） |
| | 施工进度 | PM | 进度照片（可多次） |
| | 阶段性检查 | Z | 检查记录 |
| | agent 介入 | J | 无，手动勾 |
| | ◆ final | D、J 确认 | final 检查通过 |
| ⑤ 卖 | staging | J | staging 照片 |
| | 上市 | J | 挂牌日期、挂牌协议 |
| | 园丁剪草 | A 安排、园丁做 | 剪草后照片 |
| | ◆ 收到 offer | D、J 确认 | offer 文件 |
| | 卖房文件 | S、W | 卖房文件包 |
| | seller disclosure | K | 披露文件 |
| | 签卖房文件 | D | 签署版 |
| | ◆ 交割完成 | D、J 确认 | 成交日期、成交结算单 |
| | 关水电瓦斯、退保险 | K | 三家账户都"已关闭" |

permit 范围按常识定的默认值（每套房可改）：动结构、加建、屋顶、水电气管线、暖通、改窗洞要办；清理、搬运、非结构拆除、刷漆、换地板台面柜子灯具不用。

## 3. 角色与权限（四级，颜色分级）

| 级 | 颜色 | 角色 | 能看 | 能改 |
|---|---|---|---|---|
| 紫 决策 | 紫 | 老板、D、J | 全部，含买卖价、预算、利润、交易分析 | 确认大节点（D、J 各自）；定价；蓝能做的都能做 |
| 蓝 统筹 | 蓝 | 负责人、L、PM | 全部，含钱 | 项目字段、风险备注；代任何人打勾（记"代勾"）；代 D/J 确认（仅负责人）；预算、支出；水电瓦斯、检查记录；传任何文件 |
| 青 执行 | 青 | K、Z、S、W、A、设计师 | 项目清单、文件、数据页；**看不到**买卖价、预算、利润、分析、预算页签 | 只勾自己名下的事、交自己那一步的文件 / 照片 / 记录 |
| 灰 外部 | 灰 | 园丁、承包商 ⚠ | 只有"我的待办" | 只传自己那一步的照片 |

| 负责人（蓝） | 完整工作台 | 全部 | 改项目字段、风险备注；代勾任何事；代 D/J 确认；传任何文件 |

| K（青） | 我的待办 | 总览、文件、数据 › 水电瓦斯 | 交保险单、seller disclosure；填水电瓦斯账户；关水电 |

系统里怎么看：顶栏"我是"切身份，顶栏下方一根色条就是当前级别的颜色；每个人的圆标也按级别上色。

## 5. 演示脚本：切换身份把一套房走完

从工作台右上角"新建项目"开始（用 J），之后每步切到对应身份，在项目页"总览 › 现在到哪一步"里点那一行的按钮：

1. **J** 新建项目（地址库里还没用过的地址，比如随便输一个）→ "筛选房源"自动 ✓，点"写风险"填风险
2. **L** 看房 → 交照片；**D** 董事会定价 → 填价格；**D、J** 各勾一次 Open escrow → 段①收起
3. **K** 保险单（填到期日）；**D** loan doc；**L** 量尺记录；**设计师** 方案图纸；**D、J** Close escrow；**K** 去数据页把三家账户改"已开通"
4. **设计师** 定稿图纸；**Z** 申请回执；**PM** 现场照片；**Z** permit 文件；**D、J** 可以开工
5. **J** 去预算页记一笔支出；**PM** 进度照片；**Z** 在"检查记录"里记一次通过；**J** 勾 agent；**Z** 记 final 通过；**D、J** final
6. **J** staging 照片；**J** 填挂牌日期；**园丁** 剪草照片；**D、J** 收到 offer；**S** 卖房文件包；**K** disclosure；**D** 签署版；**D、J** 交割完成；**K** 三家改"已关闭" → 全部完成

切错身份时，那一行只显示"等 X"，没有按钮；硬调接口会返回 403。
