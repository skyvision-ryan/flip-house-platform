## 完成标准

- 每张执行单提交代码与必要测试、迁移和说明；commit/PR 标题包含单号，票内回填链接与验证结果。不要只写“已 push”而没有结果。
- 一张执行单按一次功能 push 规划；若发现范围超出，继续在原 Epic 下拆分并更新映射，不把未验证的大改动硬塞成一次提交。
- 所有执行单完成后，Epic 仍须通过整体验收。真实 iPhone、AWS 登录、数据恢复分别需要实际证据，不能用模拟或仅有脚本代替。
- 三个 Epic 原生优先级为 Highest。执行单的优先级与截止日期已写入 Jira 原生字段：本周 demo 链（KAN-20–21、27–34）为 Highest，下周 AWS（KAN-22–26）为 High；标签用 `demo-0918` / `aws-trial-0925` 与 `backend` / `frontend` / `mobile` / `infra` / `auth`。
- 当前 Jira 经办人为 ryanlian。KAN-20 已完成，其余执行单为待办；后续以实际 Jira 状态和提交记录为准。
