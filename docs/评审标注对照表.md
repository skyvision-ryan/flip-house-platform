# 评审标注对照表

> 2026-09-15 状态说明：历史界面评审索引。字母和页面位置需按实际版本复核；本轮产品方向和 iPhone 验收优先。 当前 AI 入口见 [AGENTS](../AGENTS.md)，交付顺序见 [ROADMAP](../ROADMAP.md)，产品原则见 [当前方向](产品方向与执行原则.md)。本文件保留原始历史内容。

界面上每个功能块的标题前有一个黄底黑字的字母圆标。同一页面（或页签）内从 A 开始编号。开会记录时写“页面名 + 字母”，例如“总览 C 改进：关键信息里加上每平尺单价”。

顶栏右侧“评审标注：开/关”可以隐藏或显示这些圆标，设置记在本机浏览器里。

黄圆标旁边的**彩色圆标**是“这一块由谁负责”，字母是负责人手写流程里的代号（A D J K L S W Z，J 是 Jessie），PM / 设计师 / 园丁 / 负责人用胶囊显示。颜色是级别：紫 决策（老板、D、J）、蓝 统筹（负责人、L、PM）、青 执行（K、Z、S、W、A、设计师）、灰 外部（园丁、承包商）。顶栏“我是”切身份，顶栏下面一根色条就是当前级别。青、灰身份看不到钱，首页只有“我的待办”。顶栏“我是：负责人 ▾”可以切换身份：谁在填就选谁，上传的文件、勾的清单、记的支出都会记在这个人名下。

## 怎么记备注

每张表最后一列“备注”留给开会时填。建议写法：`日期 · 谁提的 · 要改什么 · 优先级（高/中/低）`，例如 `09/10 · 老板 · 关键信息加每平尺单价 · 中`。
一个功能块有多条意见就用 `；` 隔开。不属于某个块的整体意见写到文末“跨页面 / 整体意见”表里。

**按身份动态组合**：每个身份有自己的默认布局（`DASHBOARD_LAYOUTS`），老板、负责人最全；蓝的 L、PM 没有钱类；青只有待办 + 职位相关的一两个 + 更新记录；灰只有待办。"添加小组件"只列自己能加的。布局按身份分别记在本机浏览器。今日概览 A 对看不到钱的身份显示"轮到我 N 件"代替投入和利润。

小组件可拖动、缩放、移除，字母跟着小组件走；移除后可从右上角“添加小组件”加回。
