**提醒与一致性**：新增 `task_evidence_states` 仅保存上次条件布尔值，用任务主键与条件更新去重；业务写入、状态观察和既有 `TaskEvent` 在同一事务提交。首次观察旧资料只建基线，不伪造刚完成；重复保存不重复提醒；证据删除或撤销导致失效时记录需补充。GET 不写提醒，不猜历史完成日期，事件时间是条件变化被系统观察的时间。MyTask / 工作台只在当前账号既有项目范围读取事件，不泄露金额或文件内容。没有已读状态，不称未读，也没有邮件或手机推送。下一项只从本房已有分派、尚未满足且未等待的非采购任务中按阶段、到期日排序推荐；不会自动分派、改阶段或排程。

**页面**：MyTask 复用总览路线、字段、文件、照片、水电及检查入口；照片可直接预览，文件保留原件链接。普通任务保留负责人、期限、等待 / 恢复及全部历史；隐藏不再适用的审核动作。切换房屋按房屋键隔离详情，房屋筛选同时约束提醒；保存后刷新条件与路线，但不重挂载编辑器。中英文静态词库继续随应用交付，员工备注不自动翻译。
